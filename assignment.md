Assignment 4.4 — Metadata & Page Setup

What to build: Update your old HTML projects with proper metadata.

Steps:

1. Set UTF-8 for character encoding in every HTML file.
2. Add a mobile viewport meta tag.
3. Write a meaningful `<title>` for each page.
4. Add a meta description.
5. Add a favicon.
6. Verify that CSS links and file paths are correct.

Submission: Updated HTML files and a browser screenshot showing the favicon. Also submit the metadata code.
